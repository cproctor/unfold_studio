ANONYMOUS MODE FRONTEND MOCK

How to use
1) Unzip this folder.
2) Open anonymous_mode_frontend_mock/index.html in your browser.
3) Click “Enter Anonymous Mode” or “Sign Up / Log In” to switch modes.
4) In Anonymous Mode:
   - New Story is blocked
   - Share/Fork/Love/Add-to-book are blocked
   - Show code is hidden
   - AI prompt in the testing story shows a sign-up message
5) The nav search bar is always visible next to “New Story”.
