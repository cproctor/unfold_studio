Unfold Studio Icon Design

Precedents

Happy Mac — Susan Kare, 1984. Personality from ~8 pixels: two dot eyes, four-dot smile arc. The Mac body is secondary.

Mac OS Bomb — Susan Kare, 1984. One circle + 6-pixel fuse + 4 spark pixels. Works entirely as silhouette.

Zelda NES HUD — 1986. Hearts at ~8×8px. Items in B/A slots read at <12px because the silhouette is culturally pre-loaded.

Design lessons 1. Silhouette first — if the filled outline doesn't read, added detail won't fix it.
2. Personality from very few pixels — eyes + smile = 8 pixels = a face.
3. Use pre-loaded shapes — heart, triangle, book. Don't invent from scratch.
4. Negative space is part of the design — the bomb is mostly empty circle.

Design notes

Coherence across the set All icons share the same near-black (#231F20), the same pixel weight (1–2px lines), and the same 16×16 grid discipline. Accent colour is used only when semantically loaded: red for Love (emotion), green for Sprout (growth/nature), yellow (#ffe564) reserved for interactive/active states in CSS.
The Sprout as site identity icon The sprout is the one site-specific icon with no generic equivalent. It should appear in places that signal growth and learning — new stories, first-time user onboarding, the permeable media progression. It embodies the theoretical framework directly.
Implementation: CSS over SVG files These icons should be implemented as inline SVGs or a sprite sheet, not as image files — this allows CSS colour variables to retheme them instantly. The pixel-art button aesthetic from the staging site (stepped shadow, chamfered corners) should be applied as a CSS system, not per-element SVG.
