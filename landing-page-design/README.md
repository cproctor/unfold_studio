# Unfold Studio — Landing Page Design

Design prototype for the Unfold Studio landing page. Matches the visual style of internal pages (Browse stories, Books, New Story).

## Preview

Open `index.html` in a browser to view the prototype.

## Design notes

- Dark top navigation bar (`#3b3b3b`) — same as internal pages
- Clean, centered layout (max-width 980px)
- Hero: site title, short description, "Start Writing" CTA
- Additional section: "How Unfold Studio works"
- Same typography (monospace), spacing, and buttons as the rest of the site
- Avoids splash-style marketing; feels like part of the same site

## Files

- `index.html` — Landing page markup
- `style.css` — Styles matching internal pages (anonymous_mode/style.css)
